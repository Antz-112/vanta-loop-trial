# vanta-loop-trial

A synthetic, throwaway repository for one bounded experiment. The question: can a developer agent (Claude Code), an independent reviewer (Codex) and CI complete a develop → test → review → repair → re-review loop with no person relaying messages between them?

- Everything here is synthetic. No other project uses this code.
- Nothing is ever merged. `main` requires an approving review that no participant can give.
- Agents run only when the coordinator starts them, and only a fixed number of times. See `.github/vanta/`.

Status: **set up, not running** (Stage 1). No agent has been started.
